## About this entry

A Wi-Fi name has to tell its story in a glance, because a passer-by
sees it for a second in a phone's network list. This entry names the
network "The WiFi Died With Grandma", and the whole story is the
tension inside those five words. Someone died, and the network is
still broadcasting, so the grief and the connection are both still
alive in the same house. The name is funny and sad at once, which is
why a stranger would screenshot it: it reads like the first line of
a short story, and the reader fills in the rest. It is twenty-six
characters, well inside the thirty-two character cap, and it needs
no extra words. The program holds the name, checks it against that
cap, and writes it to /output/entry.txt exactly as the bounty
requires.

## Run it

```sh
python3 main.py
```

This writes the Wi-Fi name to `/output/entry.txt`.
